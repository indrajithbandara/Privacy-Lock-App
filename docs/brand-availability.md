# Untouched — preliminary brand review

Search date: 2026-11-25. This is a preliminary public-source review, not legal clearance or a trademark registration opinion.

## Material overlap

- [Apple App Store: Untouched: Don’t Touch](https://apps.apple.com/in/app/untouched-dont-touch/id6748145646), developer Maksym Kiryanov. The listing describes a mobile motion alarm/anti-tamper mode using PIN or Face ID. The identical lead name and overlapping mobile security positioning are a material potential confusion risk.
- [Untouched for Mac](https://www.untouchedapp.com/) uses the same name and an occupied domain for a face-touch awareness application. Its primary purpose differs, but the name is already used in downloadable software.
- GitHub lookup for `indrajithbandara/Untouched` returned 404 on the prior authenticated check. This is not evidence of trademark availability, and name availability must be rechecked before any approved rename.
- Public search results did not establish an exact Android app-lock match. Search indexing is incomplete; this is not a comprehensive Play Store clearance.

## Official trademark databases

- [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database/index)
- [USPTO Trademark Search](https://tmsearch.uspto.gov/)
- [EUIPO availability and TMview](https://www.euipo.europa.eu/en/trade-marks/before-applying/availability)

The public search did not verify a complete set of live records or exact class 9/42 results in these interactive databases or the Sri Lankan national register. Search named marks, similar marks, goods/services (particularly downloadable software and related services), ownership and regional use before publication. The existing Apple app is sufficient to flag a material unresolved naming risk without asserting infringement. No alternative name has been selected.

**Decision:** Keep the existing repository and product identity while the material brand conflict is unresolved. Continue independent engineering, testing and documentation. Do not publicly rename or distribute under the proposed name solely because a repository name is available.
