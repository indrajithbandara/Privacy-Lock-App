# Untouched: Privacy Lock — internal identity

The four corner marks represent a boundary around a U-shaped symbol. The compact mark intentionally avoids a padlock or shield. Use evergreen `#253C31`, ivory `#E7F0DC`, sage `#B8D3A6` and paper `#F5F6EF`; use the platform sans-serif with medium or semibold headings. Keep the mark clear of adjacent text by at least one corner-mark width.

The Android debug source set implements the proposed label and artwork while release branding remains unchanged pending public brand review. The inherited adaptive icon uses the overridden vector foreground and background, including the themed monochrome mask. These are original vector design assets, not application screenshots or evidence of a production build. Do not use for public distribution without clearance.
